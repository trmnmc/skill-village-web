# Skill Village

## Writing style

Write in ASD-STE100 (Simplified Technical English). Follow Zinsser's four
principles of good writing: simplicity, brevity, clarity, humanity.

In practice:

- Keep sentences short. Put one idea in each sentence.
- Use the active voice. Name who does the action.
- Give each word one meaning. Use the same word for the same thing every time.
- Choose the plain word: *use*, not *utilize*; *start*, not *initiate*.
- Cut the clutter. Remove hedges, filler, and throat-clearing.
- Stay warm and human. A person wrote this, not a manual.

This applies to prose — explanations, summaries, commit messages, documentation,
and pull request descriptions. It does not apply to code, to quoted material, or
to text whose wording the task already fixes.
