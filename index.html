Skill Village

your skills folder… is alive.

What is this?

A Tamagotchi-style game where every Claude Code skill and agent on your machine is a living pixel creature in a shared village. Your ~/.claude folder becomes a neighbourhood: each SKILL.md is a grounded little critter, each agent file gets wings, and they breathe, blink, and drift around while you work.

It's also a builder, not just a toy — the roadmap grows creatures you can hatch through an in-character interview, and what hatches is a real, installable Claude Code skill.

The villagers

Every creature is generated deterministically from its filename — same name, same creature, on any machine. Six hand-authored pixel bodies × five crowns, warm-pastel palettes, wings and dangling legs for agents. These are real outputs of the game's pipeline:

How it works

Pixel grids, not assets

A creature is ~10 strings of colour roles and two hex colours. No sprite packs, no downloads, no art pipeline — and a generated creature can't come out anatomically wrong.

Deterministic DNA

SHA-256(kind + name) seeds body, crown, and palette. The village has a stable geography: your villagers are where you left them, every load.

Your config is safe

The game reads ~/.claude and never writes to it. All state lives in ~/.skill-village. Nothing installs without an explicit confirm.

Run it locally

The village runs on your machine — it needs to see your real skills folder. Requires Node 20+.

# clone, install, play
git clone https://github.com/trmnmc/skill-village-web.git
cd skill-village-web
npm install
npm run dev
# then open http://localhost:5173
